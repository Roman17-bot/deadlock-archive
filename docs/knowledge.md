# Локальная память Deadlock

`knowledge/archive.sqlite` — частная локальная база, исключённая из Git и сайта. Node 24.15+ предоставляет SQLite/FTS5 без внешнего сервера и зависимостей. Исходники импортёра и навыка версионируются. Ни один запрос чтения не скачивает источники и не импортирует архив автоматически.

```powershell
npm run knowledge:import
npm run knowledge -- status
npm run knowledge -- search "вампиризм" --limit 5
npm run knowledge -- entity "Nurse Harrow"
npm run knowledge -- formula FORMULA_ID
npm run knowledge -- search "старая модель" --history
npm run knowledge -- decision "Краткое устойчивое решение с причиной."
npm run skill:install
```

Без npm те же команды выполняет `node scripts/knowledge/cli.mjs`. `--root PATH` задаёт репозиторий, `--db PATH` — отдельный индекс. Вывод — JSON; ошибки также JSON с ненулевым кодом. Поиск ограничен 500 символами, результаты — 1–20 записей. Слова ищутся буквально как Unicode-префиксы, соединённые AND; перевода и морфологии нет. Произвольный SQL не поддерживается. Подробности entity ограничены 14 000 символами, фрагменты поиска — 700, поэтому для полного поля иногда нужно адресно открыть исходный путь.

Таблицы: `snapshots`, `entities`, `formulas`, `evidence`, `documents`, `decisions`, `update_runs`, полнотекстовый `search_index`. Импорт сохраняет относительные пути, SHA-256, даты, версию клиента и confidence. JSON героев и механик образуют отдельные снимки. Повторный импорт одинакового содержимого не дублирует записи; предыдущие версии остаются доступны с `--history`. Формулы сохраняют ссылки на evidence и отдельную reviewed version; изменение версии героев даёт `stale`, а не автоматическую верификацию формул. Транзакция защищает предыдущую базу от частичного неудачного импорта.

Также индексируются отчёты `knowledge/current`, `knowledge/research`, `knowledge/history` и локальный кэш `knowledge/current/data/all_ability_item_assets_<clientVersion>.json` с умениями/предметами, только если версия в имени совпадает с версией `data/heroes.json`. При смене версии героев без соответствующего кэша прежние raw-сущности становятся историческими и доступны с `--history`; новый raw-кэш не создаётся автоматически. `status.rawAssets` показывает ожидаемый путь, наличие, состояние (`current`, `pending-import`, `stale` или `missing`), доступные версии и изменение файла. Изменённый кэш включает `needsImport`; отсутствие нового кэша после импорта явно видно в `rawAssets`, но само по себе не требует повторного импорта. Остальные крупные дубли raw JSON из `current/data` пропускаются. История и заменённые документы сохраняются, по умолчанию скрыты. Файлы крупнее 16 MiB пропускаются с записью в результате импорта. Время документа — mtime файла; оно не означает дату проверки источника. Ссылки/виды источников и даты проверок нужно читать внутри оригинального исследования.

Импорт ограничен деревьями доказательств и разрешёнными расширениями; не читает `.env`, логи, переписки и файлы credentials/secrets. Типовые токены и поля паролей редактируются, но это не повод складывать секреты в исследования. Короткие решения добавляются явно: базу не следует превращать в журнал всей переписки. Частный `knowledge/profile.json` хранит путь репозитория и предпочтение Nurse Harrow только для билдов/реплеев. Сайт остаётся общим для всех героев. Игра без нового разрешения не запускается.

Навык хранится в `tools/skills/deadlock-project`. Установщик копирует только его три поддерживаемых файла в `$CODEX_HOME/skills/deadlock-project` или `~/.codex/skills/deadlock-project` и создаёт там `references/local-profile.json` с локатором репозитория. После переноса папки нужно переустановить навык. Установленные локальные профили не публикуются. Навык сначала получает актуальное состояние базы, затем маршрутизирует к небольшим запросам и нужным источникам; числа патча не зашиты в его входной файл.

Baseline до навыка: независимый агент восстановил основного героя, две модели LS и отсутствие реализованного updater, прочитав 9 файлов и отдельно обнаружив ignored research. Нарушений требований не наблюдалось. Выявленный практический недостаток — стоимость ручного поиска и устаревшая навигация `00_INDEX.md`, не отражающая новые исследования 25 октября и актуальные команды. Навык создан по явному запросу пользователя и уменьшает этот путь через динамический status/FTS; это улучшение retrieval, а не исправление вымышленного нарушения.

При успешном обновлении данных вызывается `importKnowledge({ root })` из `scripts/knowledge/import.mjs`. Сбой индексирования должен сообщаться отдельным предупреждением, сохраняя факт успешного сохранения JSON. Сама база ничего не публикует. Для текущих игровых утверждений всё равно нужна свежая проверка патча в первичных источниках; старые билды, статистика и модели не становятся текущими из-за повторного импорта. Видео из ссылок не выдаются за просмотренные реплеи.
