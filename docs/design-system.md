# Визуальная система «Полночное бюро»

Deadlock Archive оформлен как ночное городское бюро: тёмная зелень, светлая наборная бумага и тёплая латунь. Расположение поиска, фильтров, таблицы, калькулятора, истории и действий сохранено. Схемы данных и расчёты не зависят от оформления.

## Слои оформления

- `src/styles/tokens.css` — палитра, шрифты, поверхности, состояния, rail/thumb уровня и три цвета магазина. Оружие/выживаемость/спирит сохраняют оранжевый/зелёный/фиолетовый.
- `src/styles/global.css` — общие элементы, header/footer, кнопки, окно методики и responsive chrome. Основной текст остаётся не меньше прежнего размера.
- CSS рядом со страницами и компонентами — оформление их существующих областей. Сетки и порядок не дублируются во второй «теме» с сотнями overrides.
- `src/styles/motion.css` — короткие появления меню/подсказки/окна и отклик навигации. `useActionMotion` отвечает только за декоративную реакцию SVG внутри кнопок.

Тёмные поверхности используют `--paper`/`--muted` и `--focus`. На светлой бумаге нужны `--on-paper`, `--on-paper-muted`, `--on-paper-line`, `--on-paper-focus`; тёмные и светлые текстовые токены не взаимозаменяемы. Выбранность обозначается также подписью, рамкой, check или aria-pressed.

## Типографика и ресурсы

Prata normal400 используется в крупных титулах и wordmark. Golos Text используется в интерфейсе, небольших заголовках, числах и подписях формул; табличные значения имеют tabular/lining nums. Длинные мобильные заголовки подстраиваются по ширине без уменьшения основного текста.

Новые WOFF2 подключены через `public/assets/fonts/archive-fonts.css`; кириллица и латиница размещены локально, font-display:swap. Это отдельный URL, чтобы старый кэш fonts.css не задерживал появление новых семейств. Источники: Google Fonts Prata/Golos Text, рядом сохранены их SIL OFL1.1. Старые ресурсы остаются доступными для ранее закэшированных сборок.

## Логотип и иконки

`ArchiveLogo` возвращает прежний одиночный D в гравированной рамке: пользователь отверг монограмму DA 30 октября. Знак занимает прежнее место в шапке и декоративное место на главной. При наведении/фокусе внешний контур прорисовывается за650ms; при reduced motion рамка остаётся неподвижной. Favicon использует этот D по новому адресу `archive-emblem.svg`, чтобы прежний кэш не возвращал DA.

`src/components/ui/ArchiveIcon/ArchiveIcons.tsx` — проектный набор из68 SVG на сетке24×24 со штрихом1.75. Восемь заметных знаков доработаны; для них используются округлённые окончания/соединения. Прицел упрощён до кольца, центра и четырёх осей для чтения в малом размере. Именованные экспорты поддерживают size, strokeWidth, SVG props, children и ref. Пример:

```tsx
import { Search } from './ArchiveIcons';
<Search size={18} />; // Декоративная иконка рядом с HTML-подписью.
<Search aria-label="Search archive" />; // Самостоятельное изображение.
```

Обычные значки скрыты от screen reader; явная доступная подпись раскрывает SVG как изображение. `data-archive-icon` связывает готовый знак с откликом, не меняя логику кнопки. Редактируемые исходники графики и пробные варианты сохраняются в частном каталоге дизайнера; в приложении используются только итоговые пути и SVG.

## Движение

`LanguageSwitch` — отдельный компонент рядом с Header. Медная пластина проходит между двумя неподвижными табличками RU/EN за400ms. Светлые подписи на непрозрачных тёмных табличках читаются также посередине перехода. Выбор языка и размещение кнопок сохраняют прежнюю семантику.

Категории используют непрозрачные цветные клавиши с опорной гранью; тиры — прямоугольные штампы со светлым выбранным состоянием; активация — округлённые клавиши с300ms откликом посадки. Обычные действия имеют собственную глубину и нажатое состояние. Декоративные блики/тени не делают поверхность кнопки полупрозрачной. Фокус остаётся снаружи декора и не обрезается.

Сброс прокручивает значок за420ms, upload/download дают300ms отклик. `useResultMotion` перемещает выдачу/новую задачу калькулятора на10px с возвратом за300ms; текст, указатель и обработчики доступны сразу. В каталоге движение связано только с категориями/тирами/свойством/активацией, а набор поискового запроса остаётся неподвижным. Цветная граница результата прорисовывается за360ms. Повтор отменяет прежний эффект, смена reduced motion и unmount очищают принадлежащие компоненту Animation. При недоступной API действие работает.

Раскрытие групп свойств использует400ms height transition только в браузерах с `interpolate-size` и `::details-content`; базовое native details остаётся рабочим без этой поддержки. Появление меню/tooltip —280ms, окна методики —340ms. Реальные образцы промежуточного движения хранятся в частной проверке; они не являются измерением FPS.

CSS-эффекты имеют reduced-motion альтернативу. Нет анимированных числовых счётчиков, фоновых циклов, массового появления всех карточек или новой библиотеки анимаций. Проверка настоящей плавности проводится в браузере; unit-тесты подтверждают логику жизненного цикла, а не FPS.

Изменения визуальной системы проходят designer → designcritic → website/координатор → сравнение фактических экранов. Общие рамки: [design-brief.md](design-brief.md).

## Основное оформление Heritage

Обычная ссылка открывает всё приложение в зелёной, слоновой кости и золотой палитре Heritage, выбранной пользователем30октября. Прежние ссылки `/?theme=heritage#/` продолжают работать. Navy/copper можно открыть явно по `/?theme=noir#/`; меню выбора темы в интерфейс не добавлено.

`index.html` сразу содержит Heritage data-theme, theme-color и favicon для первого отображения страницы. `src/app/appearance.ts` принимает только известное значение query для альтернативы, применяет data-theme до рендера React и обновляет метаданные с сохранением Pages-префикса. Выбор относится к ссылке и сохраняется при переходах по hash-маршрутам; localStorage для него не используется.

`src/styles/themes/heritage.css` содержит изолированные токены и формы: латунные основные действия с угловыми насечками, категории с плотной коричнево-оранжевой/зелёной/фиолетовой заливкой и небольшими гербовыми кругами на десктопе, римские тиры, прямоугольная активация, оливковая языковая вставка. Золото — `#d1ad66`; выбранная категория имеет галочку-штамп, тиры и активация — отдельные латунные грани. Кнопки категорий используют непрозрачные normal/hover/selected цвета без смешивания с фоном; выбранное «Все категории» имеет латунную заливку и тёмный текст. Вторичные действия остаются зелёными или светлыми. Подписи языка остаются светлыми над тёмной дорожкой и вставкой. Геометрия основных областей, шрифты, данные и lifecycle анимаций сохранены.

## Новые поверхности героев и карты

`HeroNavigation` связывает выбор героя, прежнюю таблицу характеристик и статистику матчей; остальные страницы и порядок основных действий сохраняются. Новые страницы используют Heritage-токены и локальные CSS, без отдельной темы. На всех поверхностях остаются RU/EN и вертикальная прокрутка документа.

Страница «Герои» — широкая папка с досье: слева контактный лист небольших бумажных карточек со скрепками, справа высокая витрина персонажа. Общая ширина1920px совпадает с реестром и статистикой. Карточка является обычной ссылкой на досье; hover/focus меняет предпросмотр, нажатие/Enter сразу открывает страницу. Бумажка наклоняется и приподнимается за220ms; фокус, золотая граница и галочка дополняют состояние. На сенсорном экране переход работает одним нажатием. На узких экранах витрина следует за сеткой из трёх колонок. Декоративные папка/табличка/печать — оригинальные SVG, контент и подписи — HTML. Игровые рендеры44 героев подготовлены в локальном WebP; надписи имён взяты из игровых SVG, четыре иконки и названия способностей — из текущего каталога. Рендеры повторяют игровые позы с фоном; они не являются полными3D моделями. Загружается только текущий крупный арт. При смене героя меняется его изображение, а не вся сетка; reduced motion отключает наклон и появление. Отсутствующий арт заменяется карточкой профиля, затем портретом.

Статистика — плотная таблица вместо отдельных карточек метрик. Первая колонка героя непрозрачная и закреплена по горизонтали; регион можно прокручивать, рядом есть явная подсказка. Числа табличные, сортировка объявляется через `aria-sort`. Графики 96×28 находятся внутри HTML-кнопок высотой 44px; значение процента и изменение в процентных пунктах остаются HTML-текстом. На фокусе/наведении появляется подсказка с датой, числом матчей и значением, стрелки меняют наблюдение, Escape закрывает. Пропуски не соединяются линией, недостаток наблюдений подписан. Ранг в фильтре относится к среднему рангу матча; доля выборов относится ко всем выборам героев. В интерфейсе отдельно указана недоступность статистики точной версии.

Досье героя объединяет арт/имя, игру за героя и историю/связи; в игровой части переиспользуются реальные карточки способностей и AP-кнопки калькулятора. Обычная атака и каждая способность открывают native видеодиалог. Пустое состояние «Видео пока нет» сохраняется до появления подходящего проверенного материала; декоративное видео или кадры другого героя не подставляются. Закрытие возвращает фокус к исходному действию.

Карта размещает фильтры типов, поле и карточку выбранного объекта; на узких экранах области следуют в общем потоке страницы. Формы и подписи различают типы объектов наряду с цветом. Клавиатурный выбор доступен через native список объектов; масштаб меняют отдельные кнопки, стрелки перемещают поле. Улицы/тоннели — подложки без обещания точного отбора по этажу. Карточка показывает доступные награды и таймеры, действие добавляет точку в редактируемую последовательность. В плане пользователь вводит свои времена и подтверждает доступность, неизвестные награды не заменяются нулём; линии на карте обозначают последовательность. Интерфейс прямо называет результат оценкой, не оптимальным маршрутом.
