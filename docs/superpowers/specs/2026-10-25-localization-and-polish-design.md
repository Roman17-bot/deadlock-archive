# RU/EN, калькулятор и история версий

Задача: пять доработок по запросу владельца от 25 октября 2026. Дизайн и реализация делегированы владельцем ранее; отдельного согласования не требуется.

## Решения

- Сохранить React/Vite, Node API, JSON и текущий нуарный стиль. Использовать i18next/react-i18next: переключатель RU/EN в шапке, русский по умолчанию, сохранение выбора в localStorage, корректные `html.lang`, заголовки, даты и числа. Перевести все четыре страницы, калькуляторы, модальное окно, заметки героев, пояснения и источники механик. Английские имена героев и исходные цитируемые названия публикаций сохраняются.
- Переводы интерфейса — отдельные словари; ключом служит существующий русский текст, интерполяция — `{{name}}`. Английская редакция механик хранится отдельно с теми же ID, числовыми параметрами, sourceIds и ссылками. Отсутствующий перевод новых входных данных показывать явно, без выдумывания смысла.
- Вместо системного select калькулятора — свой select-only combobox/listbox с бумажным фоном, латунным акцентом, отмеченным выбором, переносом длинного текста и ограниченной высотой меню. Клавиатура: стрелки, Home/End, Enter/Space, Escape, Tab; закрытие по внешнему нажатию.
- На телефонах калькулятор в одну колонку; на широком экране подписи парных полей занимают одинаковую строку сетки, инпуты выровнены. Минимальные ширины и переносы не допускают горизонтального переполнения.
- Сервер до полного обновления проверяет steam-info. Равная версия: успешный результат «Текущая версия актуальна», без сохранения, индексации и dispatch. Более старая или недоступная версия: понятная ошибка, предыдущий снимок цел. Новая версия: существующая полная сверка и публикация. После полной сверки unchanged также не вызывает dispatch.
- Публичная история содержит только действительно существовавшие в репозитории версии данных: clientVersion, дата сборки клиента и дата первой публикации снимка в архиве. Даты сборки и публикации явно различаются; фиктивные старые версии не добавляются. Новые версии автоматически дописываются при успешном сохранении, публикуются вместе со снимком. На странице — компактный список с текущей версией первой.

## Подходы

Автоперевод текста DOM не подходит для состояния, доступности и подробных объяснений; выбираем поддерживаемую i18n-библиотеку и редакционные переводы. Системный select сохраняет зависимость от оформления ОС; выбираем доступный собственный компонент. Локальная история браузера теряла бы версии у друзей; выбираем общий публичный JSON, обновляемый сервером и workflow.

## Проверка

Регрессии: равная версия не запускает refresh/publish, новая запускает, ошибки не затирают данные, история не дублируется. RU/EN работает на всех маршрутах и сохраняет введённые значения/сортировку; ошибки и формулы переводятся. Меню доступно с клавиатуры и касания; мобильные ширины 320/390/412, desktop 1280. Полный набор тестов, typecheck, data:check, production build и опубликованный сайт.
