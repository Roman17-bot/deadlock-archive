# Мобильный реестр и шкала уровня

Пользователь прислал скриншоты Samsung Browser: номера перекрывают портреты, таблица слишком широкая/высокая, шкала уровня почти чёрная в принудительном тёмном режиме. Решения по реализации переданы агенту ранее; работаем самостоятельно.

На мобильном <=760px сохраняем настоящую таблицу, делим числовые столбцы на «Характеристики» (5) и «Приросты за LVL» (4). Прокрутка страницы остаётся естественной, без ограничения высоты44 строк. Имя112px, числа15px, строки56px вместо90–104px; заголовки сокращены, полные названия сохранены в aria-label. Вся ячейка героя открывает примечания. Это удобнее карточек для сравнения героев и не требует уменьшать весь сайт через zoom. На desktop все9 числовых столбцов и размер18px сохраняются. CSV содержит все показатели.

Переключение сохраняет поиск/уровень; сортировка по скрытому показателю сбрасывается к имени. matchMedia синхронизирует layout при изменении ширины. Новое поведение проверяется UI тестами RED→GREEN.

Номера портретов становятся отдельной строкой под изображением на мобильном, без полупрозрачной плашки. Шкала рисуется явными WebKit/Firefox track/progress/thumb стилями: светлый золотой прогресс, светлый шалфейный остаток, контрастная обводка,22px бегунок и40px область ввода. Страница объявляет authored dark color-scheme; светлая таблица/модальное окно имеют локальную light-схему.

Важно для проверки: [Samsung описывает отдельный Force Dark](https://forum.developer.samsung.com/t/detail?id=5283), который может сообщать light preference и принудительно перекрашивать CSS вопреки схеме сайта. Объявление color-scheme соответствует [CSS Color Adjustment](https://www.w3.org/TR/css-color-adjust-1/#color-scheme-override), но не является гарантированным обходом Samsung Force Dark. Не добавляем JS детекторы, инверсию или отключение accessibility forced-colors. [Объяснение Samsung](https://developer.samsung.com/browser/blog/en/2020/12/15/dark-mode-in-samsung-internet) отдельно отмечает сложности с текстом поверх изображений. Точный Samsung-режим без телефона не выдаётся за эмулированный.

Проверка:320–412px и desktop, отсутствие пересечения подписей/изображений, плотность/полные числа, level1/27/36, обе группы/сортировка/поиск/примечания/resize, стандартные тёмные цвета и контраст дорожки, тесты/production build и GitHub Pages.
