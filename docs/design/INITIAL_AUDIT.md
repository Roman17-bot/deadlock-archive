# Исходное состояние — 30 октября 2026

До модернизации: коммит `a078d2b`, чистое рабочее дерево. Приложение React19.3.1 / TypeScript7.0.2 / Vite8.3.5, обычный CSS, i18next RU/EN, Node HTTP API и PostgreSQL. Главные области — app/pages/features/components/services; расчёты находятся в shared. Главная, герои, предметы/детали, механики/калькулятор и обновления уже работают. Heritage — выбранная пользователем основная палитра. В runtime нет Three.js, GSAP или общей motion-библиотеки: используются CSS/SVG и Web Animations API.

Команда: реестр `tools/agents/roles.json`, проектные `.codex/agents/*.toml`, команды team, частные ролевые заметки в исходном архиве. Дизайнер пишет прототипы в отдельном run; критик прежде тоже сохранял частный отчёт. Это соглашение о работе, а не отдельная OS-песочница. Пользователь просит сделать критика по умолчанию полностью read-only.

Два поддерживаемых навыка живут в tools/skills; их установщик прежде копировал их в пользовательский Codex-каталог. В пользовательском каталоге также есть Anthropic frontend-design и Vercel web-design-guidelines. Проектного `.agents/skills` нет. Глобальный конфиг содержит node_repl MCP; проектных Playwright/DevTools MCP ещё нет. Существующий CUA действительно использовался для браузерных проверок, но это отдельный доступ от новых MCP.

Инструменты: Node24.15.0, npm/npx11.12.1, Git2.50.0, Python3.13.5, Codex CLI0.133.0, установленный Chrome156.0.8078.79. Конфигурация проверялась без вывода секретов и без изменения глобальных настроек.

Сохраняем AGENTS.md, приватность knowledge/credentials/backups, оригинальные данные, архитектуру и бизнес-логику. Модернизация касается инструкций, выбранных навыков, изолированных браузерных инструментов и их проверок. Внешние исходники рассматриваются как недоверенные данные; лицензии/совместимость и необходимые установочные действия проверяются до исполнения.
