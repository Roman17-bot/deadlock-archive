- Полный прогон496тестов/47файлов; после небольшой дополнительной правки сохранения inline-comment в конфиге — повтор35соответствующих тестов. - Независимое ревью обнаружило ложный успех discovery при enabled=false. Проверка теперь требует включённые навыки именно из проектных путей;4отрицательных/положительных Python-теста покрывают disabled, чужие/global copies, проектную ошибку и постороннее предупреждение. - Установка7навыков, hashes, actual Codex discovery, два реальных MCP, snapshot/PNG/выбор/размеры/console/performance/media emulation проверены отдельно. Наличие конфигурации не выдаётся за мгновенное появление новых tools в уже открытом чате.

Для использования новых MCP в другом открытом клиенте может понадобиться переподключение/новый сеанс.
- Один ранний RED-тест установщика по ошибке затронул пользовательские копии двух собственных навыков. Координатор восстановил9прежних файлов и валидный исходный locator из baseline; затем добавил изоляцию CODEX_HOME в тестах. Новая версия устанавливалась только в проект.
