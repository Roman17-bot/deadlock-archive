# Asset attribution

Deadlock character portraits and feature artwork are Valve assets, obtained from the public asset links in the version-pinned Deadlock API hero records: https://api.deadlock-api.com/v1/assets/heroes?client_version=6819 . They are used by this unofficial, non-commercial fan reference. Valve retains rights to its game, characters, marks and artwork.

Cormorant Garamond and Manrope are served locally from Google Fonts under the SIL Open Font License. See fonts/README.txt. Website layout and CSS are original project code; the code license does not relicense third-party assets.
